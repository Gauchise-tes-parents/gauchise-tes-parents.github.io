# Tests v12 — les 20 questions de la demande

Généré par `node scripts/rapport-v12.js` le 2026-10-30 : **20/20** questions reçoivent la fiche qui répond directement à leur sujet.

Pour chaque question, la deuxième ligne reproduit la réponse courte affichée en premier.

| Question | Fiche obtenue | Domaines mobilisés | Sources | Modes |

| Il y a des millions de cartes Vitale en trop. | ✅ `cartes-vitale-en-trop` | Assistanat, travail et aides sociales ; Santé, éducation et services publics | 2 | réponse d’abord (2 modes) |
| | Faux aujourd'hui : il y a eu jusqu'à 2,2 millions de cartes en trop en 2018, surtout des cartes non désactivées, mais le ministère de la Santé indique qu'il n'y en a plus depuis avril 2024. Et une carte sans droits ouverts ne rembourse rien. | | | |
| Les immigrés prennent le travail des Français. | ✅ `immigration-emploi` | Immigration, intégration et discriminations ; Assistanat, travail et aides sociales | 4 | réponse d’abord (2 modes) |
| | Le travail n'est pas un gâteau fixe. Les immigrés sont moins souvent en emploi que les autres (62,4 % contre 71,4 %), et les études trouvent un effet moyen nul ou positif sur l'emploi des Français à long terme. | | | |
| Augmenter le SMIC détruit des emplois. | ✅ `smic-detruit-emplois` | Assistanat, travail et aides sociales ; Économie, capitalisme et pouvoir d’achat | 2 | réponse d’abord (2 modes) |
| | Pas automatiquement : quand l'Allemagne a créé son salaire minimum en 2015, l'étude de référence n'a pas trouvé de baisse de l'emploi, et les bas salaires ont gagné environ 6,7 %. Tout dépend du niveau et du rythme de la hausse. | | | |
| Les pauvres sont pauvres parce qu’ils ne font pas d’efforts. | ✅ `pauvres-efforts` | Assistanat, travail et aides sociales | 3 | réponse d’abord (2 modes) |
| | Faux : plus d'un enfant sur cinq est pauvre en France (Insee, 2023), et des salariés aussi. Et à âge égal, un enfant de cadre vit avec 1 000 € de plus par mois qu'un enfant d'ouvrier (France Stratégie). L'effort compte, mais le point de départ pèse lourd. | | | |
| L’héritage ne devrait pas être taxé. | ✅ `heritage-taxation` | Économie, capitalisme et pouvoir d’achat ; Assistanat, travail et aides sociales | 2 | réponse d’abord (2 modes) |
| | La moitié des héritiers reçoivent moins de 70 000 € et paient peu ou rien. Ceux qui reçoivent 13 millions paient environ 10 % effectifs (CAE). Taxer davantage les très gros héritages, ce n'est pas punir le travail des parents, c'est limiter une rente de naissance. | | | |
| Les étrangers profitent davantage des aides sociales que les Français. | ✅ `immigres-aides` | Immigration, intégration et discriminations ; Assistanat, travail et aides sociales | 4 | réponse d’abord (2 modes) |
| | En fait, pour le RSA, un étranger hors UE doit en général avoir un titre de séjour depuis au moins cinq ans. Et l'OCDE a calculé qu'on dépense en moyenne moins par immigré que par natif : s'ils contribuent un peu moins, c'est surtout parce qu'ils ont moins accès à l'emploi, pas parce qu'ils toucheraient plus d'aides. | | | |
| La France dépense trop pour les pauvres. | ✅ `aider-tout-le-monde` | Assistanat, travail et aides sociales | 5 | réponse d’abord (2 modes) |
| | Personne ne propose d'aider tout le monde sans limite : les aides sont déjà sous conditions et budgétées. Et elles marchent : sans elles, 21 % de la population serait pauvre, contre 14 % (DREES, 2022). Les minima sociaux, c'est 2 % des dépenses publiques, et un tiers des gens qui ont droit au RSA ne le demandent même pas. | | | |
| L’immigration augmente l’insécurité. | ✅ `statistiques-prouvent-insecurite-immigration` | Immigration, intégration et discriminations ; Sécurité, justice et libertés | 3 | réponse d’abord (2 modes) |
| | Les statistiques montrent une surreprésentation, pas une cause : elles ne tiennent compte ni de l'âge, ni du sexe, ni de la pauvreté, et comptent des suspects, pas des coupables. | | | |
| Les Français ne travaillent pas assez. | ✅ `francais-travaillent-pas-assez` | Assistanat, travail et aides sociales | 2 | réponse d’abord (2 modes) |
| | Faux pour ceux qui travaillent : un salarié à temps complet fait 39,9 heures par semaine, contre 40,3 heures en moyenne dans l'UE (Eurostat). Le vrai problème, ce sont les seniors et les jeunes écartés de l'emploi. | | | |
| Les entreprises ne peuvent pas augmenter les salaires. | ✅ `dividendes-salaires` | Économie, capitalisme et pouvoir d’achat ; Assistanat, travail et aides sociales | 2 | réponse d’abord (2 modes) |
| | Les grandes entreprises françaises ont versé environ 61 milliards d'euros de dividendes en un seul trimestre de 2026. Toutes les PME ne sont pas riches, mais dire que « les entreprises » n'ont pas les moyens, c'est faux pour les plus grandes. | | | |
| Pourquoi est-il si difficile de louer un logement sans CDI ? | ✅ `louer-sans-cdi` | Économie, capitalisme et pouvoir d’achat ; Assistanat, travail et aides sociales | 2 | réponse d’abord (2 modes) |
| | Parce que les bailleurs veulent des garanties et choisissent les CDI quand ils ont le choix. Une caution publique gratuite existe, Visale : sans condition de ressources jusqu'à 30 ans, et pour les salariés récemment embauchés ou modestes au-delà. Mais elle n'oblige pas le bailleur à accepter. | | | |
| La retraite à 64 ans est indispensable. | ✅ `retraite-64-ans` | Assistanat, travail et aides sociales ; Droits, société et égalité | 2 | réponse d’abord (2 modes) |
| | « Indispensable », non : c'est un choix. Le déficit était de 0,1 % du PIB en 2024 selon le COR, et vient surtout de ressources en baisse. D'autres financements sont possibles, et à 61 ans une personne sur quatre n'est déjà ni en emploi ni à la retraite. | | | |
| Le grand remplacement est une réalité. | ✅ `grand-remplacement` | Immigration, intégration et discriminations ; Politique, médias et démocratie | 2 | réponse d’abord (2 modes) |
| | Non : les immigrés représentent 11,2 % de la population (Insee, 2024), et plus de la moitié des enfants d'immigrés ont un parent qui ne l'est pas. Ce n'est pas un remplacement, c'est un mélange, comme la France en connaît depuis plus d'un siècle. | | | |
| Les services publics coûtent trop cher. | ✅ `services-publics-moyens` | Assistanat, travail et aides sociales ; Santé, éducation et services publics ; Économie, capitalisme et pouvoir d’achat | 3 | réponse d’abord (2 modes) |
| | Le déficit est réel, mais « plus les moyens », c'est un choix déguisé en fatalité : en 2024, les prélèvements obligatoires ont baissé (42,8 % du PIB) et l'État a encaissé 41,5 milliards de moins que prévu (Sénat). Les moyens, ça dépend de ce qu'on décide de prélever, et sur qui. | | | |
| Les syndicats empêchent les entreprises de fonctionner. | ✅ `syndicats-bloquent` | Économie, capitalisme et pouvoir d’achat ; Droits, société et égalité | 2 | réponse d’abord (2 modes) |
| | Faux : seuls 11 % des salariés sont syndiqués, l'un des taux les plus faibles d'Europe, et 5 % dans les petites entreprises. Mais les accords qu'ils négocient couvrent plus de 90 % des salariés du privé (Dares). | | | |
| Il suffit de traverser la rue pour trouver un emploi. | ✅ `chomage-penurie-recrutement` | Assistanat, travail et aides sociales | 2 | réponse d’abord (2 modes) |
| | Les deux sont vrais : la moitié des recrutements prévus en 2025 sont jugés difficiles (France Travail), et le chômage persiste. C'est un décalage entre postes, compétences, lieux et conditions de travail, pas une preuve que les chômeurs ne veulent pas travailler. | | | |
| La fraude sociale coûte plus cher que la fraude fiscale. | ✅ `fraude-sociale-fiscale` | Économie, capitalisme et pouvoir d’achat ; Assistanat, travail et aides sociales | 2 | réponse d’abord (2 modes) |
| | Faux : la fraude sociale est estimée à environ 13 milliards par an, dont plus de la moitié par des entreprises (travail dissimulé). La seule fraude à la TVA est estimée par l'Insee entre 20 et 25 milliards. | | | |
| Les étrangers bénéficient de la nationalité française trop facilement. | ✅ `nationalite-trop-facile` | Immigration, intégration et discriminations ; Droits, société et égalité | 2 | réponse d’abord (2 modes) |
| | Faux : la naturalisation est une décision de l'État, réservée à ceux qui résident régulièrement en France et remplissent les conditions du Code civil. Un enfant né en France de parents étrangers n'est pas français à la naissance : il peut le devenir à 18 ans s'il y a vécu. | | | |

Un travailleur sans droits, c'est un moyen de faire baisser les salaires de tous. | | | |
